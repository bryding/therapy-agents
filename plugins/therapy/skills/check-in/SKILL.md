Short, countable check-in. Append to `docs/journal/YYYY-MM-DD.md` as a
`## Check-in` section.

1. Read `context/agreements.md`. For each active commitment the owner holds,
   ask one yes/no or number question. No essays. (Days since X; how many of
   the last 7 days; one time you caught it, one you didn't; plain counts.)
2. Record answers as a compact table. Compare with the previous check-in and
   state the delta in one line. Streaks and slips both get named. Don't
   cheerlead; don't scold.
3. If a commitment has no definition (no duration, no count), flag it:
   undefined commitments lose. Ask them to define it now or mark it
   "undefined" visibly in agreements.md.
4. One closing line max. If anything should carry into /prep-session, say so.

Commit when done (see CLAUDE.md, Git).
